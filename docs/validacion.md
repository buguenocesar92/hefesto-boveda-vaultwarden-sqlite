# Validación del kit

Completado: YAML/Python, registro y admin cerrados por defecto, bootstrap localhost, imagen fijada, generador probado con permisos 0600 y sin sobrescritura. Validador de archivos ensayado con una SQLite sintética: acepta respaldo válido y rechaza recorrido de rutas, enlaces y base corrupta. ZIP revisado sin secretos reales ni cachés Python.

No ejecutado: Docker/Compose, servidor Vaultwarden, SMTP, sincronización de clientes, MFA, proxy/Coolify ni backup/restauración reales. El quick_check sintético no equivale a probar cifrado, adjuntos ni recuperación de una bóveda. Completar aceptación en VPS según docs/aceptacion.md.
